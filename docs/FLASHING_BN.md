# ESP32 Network Shield — ফ্ল্যাশিং গাইড (বাংলা)

এই গাইডে ধাপে ধাপে দেখানো হয়েছে: ESP32 বোর্ড কীভাবে কম্পিউটারের সাথে সংযোগ করবেন, GitHub থেকে কোন ফাইল নিতে হবে, ফ্ল্যাশ করতে কোন ID লাগবে, এবং পুরো সিস্টেম কীভাবে বোর্ডে আপলোড করবেন। আগে কখনো ESP32 ফ্ল্যাশ না করে থাকলেও এই গাইড অনুসরণ করে পারবেন। কোনো সোল্ডারিং বা তারের সংযোগ লাগবে না — শুধু USB কেবলই যথেষ্ট।

## ১. যা যা লাগবে

- একটি ESP32 ডেভেলপমেন্ট বোর্ড (প্রোটোটাইপ হিসেবে যেকোনো ক্লাসিক ESP32 চলবে; ESP32-S3 হলে আরও ভালো)
- **ডেটা ট্রান্সফার সমর্থনকারী USB কেবল** — এটা সবচেয়ে জরুরি। অনেক সস্তা কেবল শুধু চার্জ দেয়, ডেটা পাঠায় না। এমন কেবল দিয়ে বোর্ডে লাইট জ্বলবে কিন্তু কম্পিউটারে কোনো পোর্ট দেখা যাবে না। পোর্ট না পেলে আগে কেবল বদলে দেখুন।
- Windows, Linux বা macOS চালিত একটি কম্পিউটার

## ২. GitHub থেকে কোড নেওয়া (কোন ফাইল ক্লোন করবেন)

একটি মাত্র ফাইল নয় — **পুরো রিপোজিটরি** ক্লোন করতে হবে, কারণ ফার্মওয়্যার অনেকগুলো ফাইল মিলে তৈরি:

```bash
git clone https://github.com/MontasirOpi/esp32-network-shield.git
cd esp32-network-shield
```

Git ইনস্টল না থাকলে বিকল্প উপায়: ব্রাউজারে https://github.com/MontasirOpi/esp32-network-shield ঠিকানায় গিয়ে **Code** বোতামে ক্লিক করে **Download ZIP** নির্বাচন করুন, তারপর জিপ ফাইলটি আনজিপ করুন।

## ৩. ESP32 কম্পিউটারের সাথে সংযোগ করা

1. USB কেবল দিয়ে বোর্ডটি কম্পিউটারে লাগান। বোর্ডের পাওয়ার LED জ্বলে উঠবে।
2. **ড্রাইভার ইনস্টল করুন** (পোর্ট না দেখা গেলে): বোর্ডের USB পোর্টের পাশের ছোট চিপটি দেখুন —
   - **CP2102** (চারকোনা চিপ) হলে [Silicon Labs CP210x ড্রাইভার](https://www.silabs.com/developers/usb-to-uart-bridge-vcp-drivers) ইনস্টল করুন।
   - **CH340 / CH341** (লম্বাটে চিপ) হলে [WCH CH341SER ড্রাইভার](https://www.wch.cn/downloads/CH341SER_ZIP.html) ইনস্টল করুন।
   
   বেশিরভাগ সস্তা বোর্ডে CH340 থাকে। Windows 10/11-এ অনেক সময় ড্রাইভার নিজে থেকেই ইনস্টল হয়ে যায় — পোর্ট দেখা না গেলেই শুধু ম্যানুয়ালি ইনস্টল করবেন।
3. **পোর্টের নাম (ID) বের করুন** — ফ্ল্যাশ করার সময় এটা লাগবেই:
   - **Windows:** Device Manager খুলুন → *Ports (COM & LPT)* → `USB-SERIAL CH340 (COM5)` এর মতো একটা লাইন দেখবেন। `COM5` অংশটাই পোর্ট ID — নোট করে রাখুন।
   - **Linux:** বোর্ড লাগানোর পর টার্মিনালে `dmesg | tail` চালান — `now attached to ttyUSB0` এর মতো লাইন দেখাবে, অর্থাৎ পোর্ট হলো `/dev/ttyUSB0`। "permission denied" এলে `sudo usermod -aG dialout $USER` চালিয়ে লগ-আউট/লগ-ইন করুন।
   - **macOS:** টার্মিনালে `ls /dev/cu.*` চালান — `/dev/cu.usbserial-*` বা `/dev/cu.wchusbserial*` এর মতো নাম পাবেন।

## ৪. ফ্ল্যাশ করতে কোন ID লাগবে?

সংক্ষেপে — **শুধু পোর্টের নামটাই লাগবে**, আর কিছু না:

| জিনিস | লাগবে? | ব্যাখ্যা |
|---|---|---|
| পোর্ট ID (যেমন `COM5`, `/dev/ttyUSB0`) | ✅ হ্যাঁ | `idf.py -p PORT flash` কমান্ডে `PORT`-এর জায়গায় এটা বসাতে হবে |
| চিপের ID / MAC address | ❌ না | ফ্ল্যাশ টুল নিজে থেকেই শনাক্ত করে নেয় |
| অ্যাকাউন্ট, লাইসেন্স কী বা পাসওয়ার্ড | ❌ না | কিছুই লাগে না — সম্পূর্ণ ফ্রি ও ওপেন |

## ৫. ESP-IDF ইনস্টল করা (একবারই করতে হবে)

ফার্মওয়্যার বিল্ড করতে **ESP-IDF v5.1 বা নতুন** লাগবে। বিস্তারিত: [Espressif Get Started](https://docs.espressif.com/projects/esp-idf/en/v5.1/esp32/get-started/index.html)। সংক্ষেপে:

- **Windows (সহজ উপায়):** [ESP-IDF Windows Installer](https://docs.espressif.com/projects/esp-idf/en/v5.1/esp32/get-started/windows-setup.html) চালান। ইনস্টলের পর **"ESP-IDF PowerShell"** নামে একটা শর্টকাট পাবেন — নিচের সব কমান্ড সেই টার্মিনালেই চালাবেন।
- **Linux / macOS:** ESP-IDF ক্লোন করে একবার ইনস্টল স্ক্রিপ্ট চালান, তারপর প্রতিবার নতুন টার্মিনালে এক্সপোর্ট স্ক্রিপ্ট:
  ```bash
  ./install.sh              # শুধু একবার, $IDF_PATH-এর ভেতরে
  source $IDF_PATH/export.sh  # প্রতিটা নতুন টার্মিনালে
  ```

`idf.py --version` চালিয়ে দেখুন — v5.1 বা তার বেশি হলেই ঠিক আছে।

## ৬. কোড বিল্ড ও ফ্ল্যাশ করা

রিপোজিটরি ফোল্ডারের ভেতরে গিয়ে:

```bash
idf.py set-target esp32     # ক্লাসিক ESP32-এর জন্য (ডিফল্ট)
                            # ESP32-S3 হলে: idf.py set-target esp32s3

idf.py build
```

প্রথম বিল্ডে কয়েক মিনিট লাগবে (পুরো ফ্রেমওয়ার্ক একবার কম্পাইল হয়); পরের বার থেকে দ্রুত হবে। শেষে `Project build complete` দেখালে সফল।

এবার বোর্ডে আপলোড (ফ্ল্যাশ):

```bash
idf.py -p PORT flash
# Windows:  idf.py -p COM5 flash
# Linux:    idf.py -p /dev/ttyUSB0 flash
# macOS:    idf.py -p /dev/cu.usbserial-0001 flash
```

এতে বোর্ডে তিনটা জিনিস লেখা হয়: বুটলোডার, পার্টিশন টেবিল আর Shield অ্যাপ। প্রায় ১ মিনিট লাগে।

**"Failed to connect to ESP32" এলে:** বেশিরভাগ বোর্ড নিজে থেকেই ডাউনলোড মোডে যায়, তবে কিছু বোর্ডে হাতে করতে হয় —
1. **BOOT** বোতাম চেপে ধরে রাখুন (কোনো বোর্ডে IO0 লেখা থাকে)।
2. BOOT ধরে রেখেই **EN** (রিসেট) বোতাম একবার চেপে ছেড়ে দিন।
3. ফ্ল্যাশ শুরু হলে BOOT ছেড়ে দিন।

তাও না হলে ধীর গতিতে চেষ্টা করুন: `idf.py -p PORT -b 115200 flash`

### বুট হচ্ছে কি না দেখুন

```bash
idf.py -p PORT monitor
```

(বের হতে `Ctrl-]` চাপুন।)

সুস্থভাবে প্রথমবার চালু হলে দেখবেন: NVS init → Wi-Fi চালু → **একটা নতুন API টোকেন তৈরি (এটা কপি করে রাখুন — ড্যাশবোর্ডে লাগবে)** → `ESP32-Shield-XXXX` নামে সেটআপ Wi-Fi চালু। এগুলো দেখা মানেই ফ্ল্যাশ সফল।

## ৭. Wi-Fi সেটআপ (প্রথমবার)

1. ফোন বা ল্যাপটপ দিয়ে **`ESP32-Shield-XXXX`** Wi-Fi নেটওয়ার্কে যোগ দিন (খোলা নেটওয়ার্ক, পাসওয়ার্ড লাগে না)।
2. নিজে থেকে সেটআপ পেজ না এলে ব্রাউজারে **http://192.168.4.1** খুলুন।
3. আপনার বাসার Wi-Fi-এর **নাম (SSID)** ও **পাসওয়ার্ড** দিন, Save চাপুন। বোর্ড রিবুট হয়ে আপনার Wi-Fi-তে যুক্ত হবে।

ভুল পাসওয়ার্ড দিলে বোর্ড আবার সেটআপ মোডে ফিরে আসবে — আবার যোগ দিয়ে ঠিকটা দিন।

## ৮. রাউটারে DNS বসানো (সাধারণ মোড)

1. Shield-এর IP বের করুন: সিরিয়াল লগে Wi-Fi কানেক্টের পরের লাইন, রাউটারের DHCP লিস্ট, অথবা http://esp32-shield.local।
2. রাউটার সেটিংস → LAN/DHCP সেটিংস → DNS সার্ভারে Shield-এর IP বসান (যেমন `192.168.1.50`)।
3. ডিভাইসগুলো রিকানেক্ট করুন (অথবা DHCP রিনিউ হওয়া পর্যন্ত অপেক্ষা করুন)।

**Travel mode (যেকোনো Wi-Fi-তে প্লাগ-অ্যান্ড-প্লে):** রাউটারে হাত না দিয়ে ব্যবহার করতে চাইলে ড্যাশবোর্ড → Configuration → Mode → `travel` → Save → Reboot। তখন Shield নিজেই `Shield-XXXX` নামে Wi-Fi ছড়াবে — ডিভাইস সেখানে যোগ দিলেই বিজ্ঞাপন ব্লকিং চালু, রাউটার সেটিংস লাগবে না।

## ৯. যাচাই করুন

```bash
# ব্লকড ডোমেইন → 0.0.0.0 আসবে
dig @192.168.1.50 doubleclick.net +short

# সাধারণ ডোমেইন → আসল IP আসবে
dig @192.168.1.50 google.com +short
```

Windows-এ `dig` না থাকলে: `nslookup doubleclick.net 192.168.1.50`

তারপর ব্রাউজারে **http://192.168.1.50** (অথবা http://esp32-shield.local) খুলে API টোকেন দিয়ে ড্যাশবোর্ডে লগইন করুন — লাইভ কোয়েরি দেখতে পাবেন।

## ১০. সমস্যা সমাধান

| সমস্যা | সম্ভাব্য কারণ | সমাধান |
|---|---|---|
| কোনো COM পোর্টই দেখা যাচ্ছে না | চার্জ-শুধু USB কেবল, অথবা ড্রাইভার নেই | আগে কেবল বদলান; তারপর বোর্ডের চিপ (CP2102/CH340) অনুযায়ী ড্রাইভার ইনস্টল করুন |
| Linux-এ `/dev/ttyUSB0`-তে "permission denied" | `dialout` গ্রুপে নেই | `sudo usermod -aG dialout $USER`, তারপর লগ-আউট/লগ-ইন |
| ফ্ল্যাশে "Failed to connect to ESP32" | বোর্ড ডাউনলোড মোডে যায়নি | BOOT ধরে EN চাপুন (উপরে ৬ নম্বর ধাপ দেখুন); অথবা `-b 115200` দিয়ে চেষ্টা করুন |
| ফ্ল্যাশের সময় রিস্টার্ট/বন্ধ হয়ে যায় | USB পাওয়ার কম (brownout) | অন্য USB পোর্ট (ডেস্কটপে পেছনের পোর্ট ভালো), ছোট কেবল বা পাওয়ার্ড হাব ব্যবহার করুন |
| ফ্ল্যাশের পর বারবার রিবুট (boot loop) | ভুল টার্গেট (যেমন S3-এর বিল্ড ক্লাসিক বোর্ডে) | `idf.py set-target esp32`, `idf.py erase-flash`, তারপর আবার `flash` |
| মনিটরে অর্থহীন অক্ষর | বড রেট মিলছে না | মনিটর ডিফল্ট 115200 ব্যবহার করে; বদলে থাকলে `idf.py -p PORT monitor -b <baud>` |
| প্রথম বুটে `ESP32-Shield-XXXX` দেখা যাচ্ছে না | আগেই Wi-Fi সেটআপ করা ছিল | `idf.py -p PORT erase-flash` করে আবার ফ্ল্যাশ করুন |
| ড্যাশবোর্ড খুলছে না | বোর্ড Wi-Fi-তে যুক্ত হয়নি (ভুল পাসওয়ার্ড) | বোর্ড সেটআপ AP মোডে ফিরে গেছে — `ESP32-Shield-XXXX`-এ যোগ দিয়ে আবার সেটআপ করুন |

আটকে গেলে রিপোজিটরিতে issue খুলুন — বোর্ডের মডেল, কোন কমান্ড চালিয়েছিলেন আর শেষ ~৩০ লাইন আউটপুট দিলেই সমস্যা বোঝা যাবে।
